## 界面概览

GameForge 采用三栏布局：

| 区域 | 功能 |
|------|------|
| **左侧面板** | 组件库、场景层级、实体属性编辑 |
| **中间编辑区** | 场景编辑器、节点图逻辑编辑、代码编辑、动画时间轴 |
| **右侧预览** | 实时游戏预览，支持播放/暂停/重启/全屏 |

**工具栏**（顶部）提供：新建项目、项目名称编辑、撤销/重做、打开/保存/导出功能。

## 快速上手

### 第一步：选择模板

1. 点击工具栏左侧的 **+** 按钮
2. 在弹出的模板选择器中选择一个游戏类型
3. 编辑器将自动加载模板中的场景和实体

### 第二步：预览游戏

1. 点击右侧预览区的 **▶** 按钮
2. 使用 WASD 或方向键控制角色
3. 鼠标点击可射击（射击类模板）或交互（点击/拖拽类模板）

### 第三步：编辑与定制

1. 在左侧 **组件库** 中拖拽新实体到场景中
2. 在 **层级面板** 中选择实体
3. 在 **属性面板** 中调整位置、外观、行为参数

## 组件库

组件库包含预制的游戏实体，按类别分组：

| 类别 | 包含组件 |
|------|----------|
| 角色 | 玩家、敌人、NPC |
| 物品 & 道具 | 金币、宝石、生命值、钥匙 |
| 地形 & 障碍 | 平台、尖刺、移动平台 |
| 界面元素 | 计分板、生命显示、倒计时、文字标签 |
| 区域 & 触发器 | 胜利区、失败区、生成器 |
| 射击类 | 子弹、激光 |
| 解谜类 | 拼图块、目标区域、开关 |
| 点击放置类 | 点击按钮、自动生产器 |
| 卡牌类 | 卡牌、卡槽、牌堆 |
| 视觉小说类 | 角色立绘、对话框、选项按钮 |
| 基础形状 | 矩形、圆形、三角形 |

### 使用方法

1. 在搜索框中输入关键词快速筛选
2. 点击分类名称可以展开/折叠
3. **拖拽** 组件到中间场景编辑器中即可添加

## 场景编辑

### 基本操作

| 操作 | 方式 |
|------|------|
| 选择实体 | 在场景中点击实体 |
| 移动实体 | 选中后拖拽（编辑模式下） |
| 取消选择 | 点击场景空白处 |
| 删除实体 | 在层级面板中点击删除按钮 |

### 层级面板

在左侧切换到 **层级** 标签页，可以看到场景中所有实体的列表。每个实体右侧有：
- 👁 显示/隐藏
- 🔒 锁定/解锁
- 🗑 删除

---

## 属性面板

选中实体后，切换到 **属性** 标签页可编辑：

### 实体信息
- 名称：实体显示名称
- 类型：实体预制类型（只读）

### 变换
- 位置 (X, Y)
- 旋转角度
- 缩放 (X, Y)

### 外观
- 颜色：支持颜色选择器和十六进制输入
- 宽度、高度

### 文本
- 内容：显示文字
- 字号、颜色

### 刚体物理
- 质量、重力缩放
- 摩擦力、弹性
- 静态/触发器开关

### 行为列表
每个行为可以：
- 开启/关闭
- 编辑参数
- 删除
- 通过下拉菜单添加新行为

---

## 行为系统

行为（Behavior）是实体的核心逻辑单元。一个实体可以叠加多个行为。

### 常用行为

| 行为 | 说明 | 关键参数 |
|------|------|----------|
| 键盘移动 | WASD/方向键控制 | 速度、仅水平、跳跃力 |
| 物理移动 | 基于刚体的移动+跳跃 | 移动力、跳跃力、最大速度 |
| 巡逻 | 在指定范围内来回移动 | 速度、距离、方向 |
| 追踪玩家 | 向玩家移动 | 速度、追踪范围 |
| 重力 | 施加向下的力 | 力度、最大下落速度 |
| 可拾取物 | 玩家触碰后获得分数 | 分值、拾取后消失 |
| 障碍物 | 接触玩家造成伤害 | 伤害值 |
| 射击器 | 发射弹幕 | 射速、弹速、自动射击、瞄准鼠标 |
| 弹射物 | 按方向飞行并命中销毁 | 速度、存活时间 |
| 生命系统 | 管理实体 HP | 最大HP、无敌时间 |
| 可拖拽 | 鼠标拖动实体 | 网格吸附、限制边界 |
| 对话框 | 逐字显示对话文本 | 对话内容、速度 |
| 补间动画 | 属性值平滑过渡 | 属性、起止值、时长、循环 |
| 定时器 | 周期性触发事件 | 时长、重复、触发动作 |
| 条件检查 | 变量达标时触发事件 | 变量名、运算符、目标值 |

## 物理引擎

### 启用物理

1. 选中实体
2. 在属性面板底部点击 **+ 添加刚体物理**
3. 设置场景重力（在场景设置中调整 `gravity` 值）

### 刚体属性

| 属性 | 说明 |
|------|------|
| 质量 | 影响碰撞响应 |
| 重力缩放 | 0=不受重力，1=正常 |
| 摩擦力 | 地面摩擦系数 (0-1) |
| 弹性 | 碰撞反弹系数 (0-1) |
| 静态 | 不受力的影响但参与碰撞 |
| 触发器 | 检测重叠但不产生物理碰撞 |

### 碰撞检测

支持 AABB（矩形）和圆-圆碰撞检测，自动根据实体的形状选择。

## 节点图逻辑

切换到中间的 **逻辑节点** 标签页可进行可视化逻辑编辑。

### 节点类型

| 类型 | 颜色 | 说明 |
|------|------|------|
| 事件节点 | 绿色 | 触发逻辑的起点（游戏开始、每帧更新、点击等） |
| 条件节点 | 蓝色 | 判断条件是否成立 |
| 动作节点 | 红色 | 执行具体操作 |
| 数据节点 | 黄色 | 读写变量 |

### 使用方法

1. 从左侧节点面板拖入节点
2. 拖动节点上的连接点创建连线
3. 在节点上编辑参数
4. 逻辑会在游戏运行时自动执行

---

## 变量系统

GameForge 支持全局变量和实体级变量：

- **全局变量**：在项目设置中定义，所有行为和节点可访问
- **实体变量**：每个实体独立的变量，如 HP

内置全局变量：`score`（得分）、`health`（生命值）

变量可以被行为自动读写，也可以在节点图中操作。

## 游戏预览

右侧预览面板提供实时游戏体验：

| 按钮 | 功能 |
|------|------|
| ▶ / ⏸ | 开始/暂停游戏 |
| ↺ | 重新开始 |
| ⛶ | 全屏预览 |

### 游戏控制

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 空格 | 跳跃（平台类）/ 推进对话 |
| F / J / 鼠标点击 | 射击 |
| 鼠标拖拽 | 拖动可拖拽实体 |

底部状态栏显示当前帧率和操作提示。

## 资源管理

在左侧 **组件库** 底部的 **素材库** 区域可以管理资源：

### 支持的格式

| 类型 | 格式 |
|------|------|
| 图片 | PNG, JPG, SVG |
| 音频 | MP3, WAV, OGG |

### 操作

1. 点击上传按钮选择文件
2. 上传后的资源会显示在列表中
3. 图片资源会显示缩略图预览
4. 点击删除按钮移除资源

---

## 项目管理

### 保存

点击工具栏 **保存** 按钮将项目保存到浏览器本地存储。下次打开编辑器时会自动恢复。

### 导出 JSON

点击 **导出JSON** 按钮将项目导出为 `.json` 文件，可用于备份、版本管理或团队协作。

### 打开项目

点击 **打开** 按钮从 `.json` 文件导入项目。

### 撤销 / 重做

- **Ctrl+Z**：撤销
- **Ctrl+Shift+Z**：重做

---

## 导出游戏

点击工具栏最右侧的 **导出游戏** 按钮：

1. 编辑器会生成一个自包含的 HTML5 文件
2. 包含完整的游戏运行时（PixiJS 渲染、物理、行为、输入处理）
3. 导出的 `.html` 文件可以直接在浏览器中打开运行
4. 无需任何服务器或额外依赖

## 游戏模板

### 平台跳跃

- 玩家使用方向键移动、上键/空格跳跃
- 收集金币获得分数
- 避开敌人和陷阱
- 到达绿色终点区域通关

### 太空射击

- 方向键移动战斗机
- 鼠标瞄准并点击射击
- 消灭敌机获得分数
- 避免被敌机接触

### 解谜拼图

- 拖拽彩色方块到绿色目标区域
- 放置成功后自动吸附并计分
- 全部放置正确后通关
- 可点击重置按钮重新开始

### 点击大亨

- 点击中央按钮获得金币
- 下方生产器自动周期性产出
- 进度条显示目标进度

### 卡牌对战

- 拖拽手牌到卡槽区域
- 点击牌堆抽牌（获得分数）
- 对手卡片有浮动动画效果

### 视觉小说

- 对话逐字显示
- 点击或按空格推进对话
- 选项按钮可影响剧情变量
- 角色立绘有微妙的浮动动画

---

> 提示：每个模板都是完全可编辑的，你可以在模板基础上自由修改、添加或删除实体和行为，打造属于自己的游戏。
